# m05l04-05: The JSON habits

You can decode API responses into structs, encode reports, and reject malformed input clearly.

Use encoding JSON at the edge of a tool. Decode into a typed struct with tags for external keys, handle malformed input as an error, and encode a deliberate report shape for downstream consumers. The sooner data becomes typed, the less stringly logic spreads through the checker.

- Decode into typed structs
- Use tags for external names
- Encode stable reports
- Handle malformed input as an error
