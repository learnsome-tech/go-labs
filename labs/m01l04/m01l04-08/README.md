# m01l04-08: Try it yourself

You can choose correctly between running, building and installing a program, write functions that return a value alongside an error, format output with the verbs you will use daily, and set an exit code that a pipeline can act on.

Three tasks. Write a function that returns a percentage and an error, call it with input you know is bad, and print both results. Print a struct twice, once with the plain value verb and once with the variant that shows field names, and decide which one you would want in a log line at three in the morning. Then make the program exit with status three when some threshold is crossed, run it, and ask your shell what the exit status of the last command was. That last step is the one people skip, and it is the one that matters when your tool runs unattended.

- Write a function returning a percentage and an error, and call it with bad input.
- Print the same struct with the value verb and the plus value verb, and compare.
- Make the program exit with status three when a threshold is crossed.

Notes or exercise panel; no executable listing.
