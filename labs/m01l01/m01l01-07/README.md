# m01l01-07: Try it yourself

You can explain why platform and DevOps teams write their tooling in Go, compile and run a program with the go command, and describe exactly what the compiler hands you at the end of a build.

Your turn. Write a program that prints two lines: your name, then the words all systems nominal. Build it with a name of your choosing rather than the default, then run the resulting binary. When that works, deliberately add an import you do not use, build again, and read the error message closely: the file, the line and the column are all there, and getting comfortable reading compiler output now will save you a great deal of squinting later in the course. Then remove it and confirm the build is silent again.

- Write a program that prints your name and the words all systems nominal on two lines.
- Build it with an output name of your choosing, then run the binary.
- Add an import you do not use, build again, and read the error carefully.
