# m02l01-07: Try it yourself

You can read pointer syntax, mutate shared state deliberately, and recognise a nil pointer before it becomes a crash.

Your turn. Write a function that receives a pointer to an integer and increments the value it reaches. Call that function three times and print the final result. Then write a second function that accepts an optional string pointer. It should report that the setting is absent when the pointer is nil, and print the setting when it is present. Keep the nil check beside the dereference, and ask yourself whether a pointer is really needed for each value you pass.

- Write a function that receives a pointer to an integer and increments it.
- Call it three times and print the final value.
- Call a second function with a nil pointer and report that the setting is absent.

Notes or exercise panel; no executable listing.
