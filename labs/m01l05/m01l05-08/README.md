# m01l05-08: Try it yourself

You can declare variables both ways and say which to use where, predict the zero value of any type and design configuration structs around it, define constant sets with iota, and convert between numeric types without guessing.

Three exercises. Declare one variable of each basic type without giving it a value, print them with the quoted and boolean verbs so you can see the empty string for what it is, and write down what you expect before you run it. Define a state type with a counted constant block, and make sure the zero value is the one meaning nothing is known yet. Finally compute a percentage from two whole numbers and get two decimal places out of it, which means converting before you divide rather than after. That last one is the most common arithmetic bug in first Go programs, and doing it once by hand is the cure.

- Declare one variable of each basic type with no value and print them all.
- Define a state type with a constant block where the zero value means unknown.
- Compute a percentage from two whole numbers, correct to two decimal places.

Notes or exercise panel; no executable listing.
