# m07l04-05: The report contract

You can encode health results as stable JSON for pipelines, dashboards, and later automation.

Encode the complete result set after every check finishes. JSON tags define stable keys, standard output stays machine readable, and standard error carries diagnostics. The exit status summarizes the run for a shell or pipeline, while the document preserves the target level detail.

- Keep stdout machine readable
