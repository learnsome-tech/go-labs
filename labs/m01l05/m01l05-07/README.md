# m01l05-07: Module one, in five sentences

You can declare variables both ways and say which to use where, predict the zero value of any type and design configuration structs around it, define constant sets with iota, and convert between numeric types without guessing.

That closes module one. You can install the toolchain and use its own subcommands for formatting, checking and documentation. You can start a module, split it into packages, and build a workspace over two of them. You can run, build and install, return errors alongside values, and set an exit status a pipeline can read. And now you know that every type has a defined zero value, that constants come in counted blocks, and that numeric conversion is always your decision written out in full. Next module we build things worth passing around: pointers, slices, maps, structs with methods, and the implicit interfaces that make Go code composable.

- One toolchain, one formatter, one way to lay out a module
- Short declarations inside functions, var at package level
- The zero value is defined, useful, and worth designing around
- The counter identifier gives you enumerated constants
- Numeric conversion is always written out by you
