# m07l01-02: A typed target list

You can start the health checker with typed configuration, clear defaults, and a small target model.

Target keeps the name shown in a report beside the URL the client will call. The slice gives the project an ordered list, and the range loop prints the configuration that will drive later checks. In the real tool these values can come from flags or a JSON file, but they should become typed targets before concurrency begins.



Run: `sh run.sh`.
